# Component Organization Guide

## Architecture Overview

This project uses **shadcn/ui** as the base design system, with custom components for app-specific needs.

## Directory Structure

```
src/
├── components/ui/              # shadcn/ui components (managed by CLI)
│   ├── button.tsx
│   ├── card.tsx
│   ├── checkbox.tsx
│   ├── input.tsx
│   ├── input-with-variants.tsx  # Custom wrapper with error/size variants
│   ├── skeleton.tsx
│   ├── label.tsx
│   ├── separator.tsx
│   ├── badge.tsx
│   ├── alert.tsx
│   ├── dropdown-menu.tsx
│   └── index.ts               # Barrel exports
│
├── shared/components/
│   ├── custom/                # App-specific custom components
│   │   ├── BaseLoader.tsx
│   │   ├── CustomInput.tsx
│   │   ├── GradientMesh.tsx
│   │   └── SkipToMainContent.tsx
│   └── ui/
│       └── index.ts           # Re-exports from @/components/ui
│
└── features/
    └── [feature]/
        └── components/        # Feature-specific components
```

## When to Use What

### Use `@/components/ui/*` (shadcn/ui) when:

✅ You need standard UI primitives (buttons, inputs, cards)
✅ You want consistent, accessible components
✅ The component exists in shadcn/ui library

**Example:**

```tsx
import { Button } from "@/components/ui/button";
import { Card } from "@/components/ui/card";
```

### Use `@/shared/components/custom/*` when:

✅ Building app-specific components (loaders, backgrounds)
✅ Creating wrappers around shadcn (like CustomInput)
✅ Implementing unique UI patterns

**Example:**

```tsx
import { BaseLoader } from "@/shared/components/custom/BaseLoader";
import { CustomInput } from "@/shared/components/custom/CustomInput";
```

### Use `@/features/[feature]/components/*` when:

✅ Component is specific to one feature domain
✅ Not reused elsewhere in the app

**Example:**

```tsx
// In features/tasks/components/TaskCard.tsx
import { Checkbox } from "@/components/ui/checkbox";
```

## Component Categories

### shadcn/ui Components

**Installed and ready to use:**

- `button` - All button variants (default, destructive, outline, ghost, link)
- `card` - Card container with Header, Content, Footer
- `checkbox` - Accessible checkbox with Radix UI
- `input` - Base text input
- `skeleton` - Loading placeholders
- `label` - Form labels
- `separator` - Visual dividers
- `badge` - Status indicators
- `alert` - Alert messages
- `dropdown-menu` - Dropdown menus

### Custom Components

**BaseLoader** (`@/shared/components/custom/BaseLoader.tsx`)

- Spinning loader icon
- Used in forms and async actions

**CustomInput** (`@/shared/components/custom/CustomInput.tsx`)

- Wrapper around shadcn Input with extra features:
  - `label` - Optional label
  - `errorMessage` - Error state and message
  - `showBaseLoader` - Loading indicator
  - `variant` - "default" | "error"

**GradientMesh** (`@/shared/components/custom/GradientMesh.tsx`)

- Animated background gradient
- Used in auth pages

**SkipToMainContent** (`@/shared/components/custom/SkipToMainContent.tsx`)

- Accessibility: skip navigation link
- Required for keyboard navigation

## Import Conventions

### ✅ Preferred (Direct imports)

```tsx
import { Button } from "@/components/ui/button";
import { Card, CardHeader, CardContent } from "@/components/ui/card";
```

### ✅ Alternative (Barrel import)

```tsx
import { Button, Card } from "@/components/ui";
```

### ❌ Avoid (Old pattern)

```tsx
// DON'T: Old imports no longer exist
import { Button } from "@/shared/components/ui/Button";
```

## Customizing shadcn Components

### Option 1: Props and className

```tsx
<Button className="custom-class" variant="outline" size="lg">
  Click me
</Button>
```

### Option 2: Wrapper Component

Create in `src/shared/components/custom/`:

```tsx
import { Button, type ButtonProps } from "@/components/ui/button";

export function PrimaryButton(props: ButtonProps) {
  return <Button variant="default" size="lg" {...props} />;
}
```

### ❌ DON'T modify shadcn files directly

Files in `src/components/ui/` can be regenerated by shadcn CLI.

## Adding New shadcn Components

```bash
# Install a new component
pnpm dlx shadcn@latest add [component-name]

# Example
pnpm dlx shadcn@latest add dialog
```

This will:

1. Download the component to `src/components/ui/`
2. Install required Radix UI dependencies
3. Component is immediately usable

## Testing Components

### shadcn Components

- ✅ Test your usage, not shadcn internals
- ❌ Don't test that Button renders correctly
- ✅ Test that your form disables Button while loading

### Custom Components

- ✅ Full unit tests required
- ✅ Test all props and variants
- ✅ Test accessibility features

## Accessibility

All shadcn components include:

- ✅ ARIA attributes
- ✅ Keyboard navigation
- ✅ Focus management
- ✅ Screen reader support

Custom components must maintain the same standards.

## Styling

### Tailwind Utilities

```tsx
<Button className="mt-4 w-full">Submit</Button>
```

### CSS Variables (from globals.css)

```tsx
<div className="bg-primary text-primary-foreground">Themed content</div>
```

### Avoid Inline Styles

```tsx
// ❌ Don't
<div style={{ backgroundColor: "#6366f1" }}>

// ✅ Do
<div className="bg-primary">
```

## Migration from Old Components

If you find old import patterns:

**Before:**

```tsx
import { Button } from "@/shared/components/ui/Button";
```

**After:**

```tsx
import { Button } from "@/components/ui/button";
```
